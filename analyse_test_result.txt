========================

1) MUST checks:

3) PREFER checks:
For each PREFER item, assign rating:
- 0 = not present / opposite observed
- 1 = partially present / ambiguous
- 2 = clearly present
Provide one short evidence sentence.

Choose zero or more labels from the allowed taxonomy that explain the main miss patterns. Do NOT create new labels.

5) Score computation (0–10, alignment only):

- For each MUST failed: subtract 2.0
- For each AVOID present: subtract 1.5
- For each PREFER rating:

Clamp to [0.60,0.95].
